# Lama Alhbaby — Personal Website

A single-page digital identity built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Edit content

All site content lives in `src/config/site.ts`, including the editable email placeholder, the About copy, and the five skills. Replace `contact.email` with the real address before publishing if needed.
